So funktioniert die Buchung

1. Geprüften Gastgeber auswählen. 2. Direkt beim Betrieb buchen. 3. Falls vom Gastgeber verlangt, Buchungsgarantie/Anzahlung direkt an den Betrieb leisten. 4. Restbetrag beim Gastgeber bezahlen.

Storno-Grundmodell im Pilot: bis 7 Tage vor Anreise kostenlos; 6–2 Tage 30 %; unter 48 Stunden 70 %; No-Show maximal erste Nacht. Wird das Zimmer wieder verkauft, soll die Stornobelastung entsprechend reduziert werden.

Jeder Betrieb wird vom Plattformbetreiber einzeln freigeschaltet. Ein Betrieb kann zentral sofort ausgeblendet oder für neue Buchungen gesperrt werden. Die konkreten Vertrags-, Zahlungs- und Stornobedingungen werden beim jeweiligen Gastgeber vor Abschluss angezeigt.
